📊 ESTRUCTURA DE LA BD
════════════════════════════════════════════════════════════════════════════════

LIDERES (usuarios que pueden registrar)
  ├─ id
  ├─ usuario (único)
  ├─ email
  ├─ nombre
  ├─ contraseña (hasheada)
  └─ fecha_registro

DISCIPULOS (personas de un grupo)
  ├─ id
  ├─ lider_id (FK)
  ├─ nombre
  ├─ celular
  └─ fecha_registro

ASISTENCIA (registros diarios)
  ├─ id
  ├─ discipulo_id (FK)
  ├─ lider_id (FK)
  ├─ fecha
  ├─ presente (bit)
  ├─ celular
  └─ observación

🌍 ENDPOINTS API
════════════════════════════════════════════════════════════════════════════════

POST   /api/login                    ← Autenticar líder
POST   /api/registro                 ← Registrar nuevo líder
GET    /api/discipulos/:lider_id     ← Obtener discípulos
POST   /api/asistencia               ← Guardar asistencia
GET    /api/asistencia/:id/:fecha    ← Obtener asistencia
