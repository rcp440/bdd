1. Lee: [QUICKSTART.md](QUICKSTART.md)

### Soy Administrador (Necesito instalar y mantener)
1. Lee: [README.md](README.md)
2. Sigue: [INSTALLATION_CHECKLIST.md](INSTALLATION_CHECKLIST.md)
3. Configura: [.env.example](.env.example)
4. Si hay problemas: [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

4. Configura: `npm install` + `.env`
5. Inicia: `npm run dev`

1. Lee: [PROJECT_SUMMARY.md](PROJECT_SUMMARY.md)
